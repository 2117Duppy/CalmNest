# 🌿 CalmNest

**CalmNest** is a modern wellness and mindfulness web application designed to help users relax, track emotions, and practice healthy habits through interactive charts, calming visuals, and curated content.

![CalmNest Screenshot](./src/assets/preview.png) <!-- Replace with actual path or remove if unavailable -->

---

## ✨ Features

- 🧘 Guided relaxation UI with calm aesthetics
- 📊 Data visualization with `Chart.js` (e.g., mood tracking)
- 🌐 Fast and modular front-end built using **React + Vite**
- 🎨 Styled with **Tailwind CSS** for a sleek and responsive layout
- 📁 Well-structured and scalable folder architecture
- 🔗 Routing via `react-router-dom`

---

## 🛠️ Tech Stack

- **React** 18
- **Vite** for fast builds and hot reloads
- **Tailwind CSS** for styling
- **Chart.js + react-chartjs-2** for graphs
- **Radix UI**, **React Icons**, and more
